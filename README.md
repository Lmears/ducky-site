# ducky-site

The files GitHub Pages serves for DucKy's page. Everything here is generated: don't edit it.

The source is `kerby-promo/reels/ducky-shop/` (`page.html`, built by `site.py`). To change the page, change it
there, then:

```sh
python3 reels/ducky-shop/site.py --to ../ducky-site    # from kerby-promo
```

and commit and push here.
